  1. Create a free service

    At ulabase.com, in less than a minute. Skip this if you already have one.

  2. Set it up from this folder

    In a terminal, in this folder:

    npx ulabase login
npx ulabase setup --srv <your service id>

    It configures the service for this app and writes its URL into src/environments/environment.dev.ts, the file ng serve uses. Set src/environments/environment.ts too when you build for production.

  3. Reload

    This screen is replaced by the sign-in page, and you're in.
